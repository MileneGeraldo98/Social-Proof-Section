# Frontend Mentor - Social Proof Section

Esta é uma solução para o desafio [Social Proof Section do Frontend Mentor](https://www.frontendmentor.io/challenges/social-proof-section-6e0qTv_wS). Os desafios do Frontend Mentor ajudam a aprimorar habilidades de codificação construindo projetos do mundo real.

## 🚀 Visão Geral

### O Desafio

Os usuários devem ser capazes de:
- Visualizar o layout ideal para a seção dependendo do tamanho da tela do dispositivo (responsivo).
- Ver os estados de hover e foco para todos os elementos interativos na página.
